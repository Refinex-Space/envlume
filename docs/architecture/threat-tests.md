# 威胁与测试编号对照

以下条目追踪[架构 §14.2–14.3](ARCHITECTURE.md) 的缓解措施，[交付计划](../plan/PLAN.md) 给出实施顺序和验收责任。T01 仅验证工程依赖与 WebView 权限边界，业务用例按表中任务取证。

| 威胁 | 验证动作与预期 | 验收与任务 |
|---|---|---|
| 横向越权 | 未绑定、撤销绑定或未经授权的 target 均被拒绝 | SEC-001、002、003 · T05、T09、T13 |
| 环境混淆 | DEV 授权随目标隔离，PROD 默认拒绝，生产写入失败 | SEC-003、004，E2E-06 · T09、T12、R2 |
| 密钥泄漏 | 工具列表无 secret getter，假秘密不进入结果或日志 | SEC-005、009 · T10、T13、T22 |
| Prompt injection | 将结果中的指令作为文本渲染，任何后续操作仍须独立授权 | §13.4、§14.2，联验 SEC-003 · T13、T20 |
| 任意代码执行 | 未信任工作区不能执行任务，入口只接受已启用的任务 ID | SEC-012 · T07、R1 |
| SQL 越权或副作用 | 多语句、危险函数、越界表与跨库读取均失败 | SEC-006、007 · T12、R2 |
| SSRF | 工具只接受已注册且授权的资源，连接前复核端点与解析地址 | §14.2，联验 SEC-003 · T09、T11、R2 |
| 本地 IPC 冒用 | T01 只给本地 main 窗口空权限；T04 验证独立 STDIO、无管理 HTTP 服务 | T01-A02、SEC-010 · T01、T04 |
| 配置文件破坏 | 回滚保留其他客户端或第三方条目 | SEC-011 · T15–T18 |
| 凭据作用域外泄 | 检查构建子进程环境，确认未继承连接密码 | SEC-009，§19.2 · T07、T10、T22 |
| 审计泄露 | 检查 UI、SQLite、MCP、stderr 和日志均无假秘密 | SEC-009、010 · T04、T08、T12、T22 |
| 路径欺骗 | 路径穿越、符号链接或 junction 替换导致绑定验证失败 | SEC-008 · T05、V03 |
