# ADR-0008 · 工具链原生发现 + 显式路径，mise 为可选适配

状态为 Accepted，沿用 2026-11-23 [架构 v1.0.0 §20](../ARCHITECTURE.md) 决议。

**背景**　企业环境可能离线，多个项目依赖不同的本机工具版本。

**备选方案**　强制安装版本管理器或改动全局 PATH。

**决策与理由**　先发现本机工具，也支持显式绝对路径；mise 作为可选来源。

**风险**　失效路径、重名可执行文件或版本探测失败。

**安全影响**　按信任、来源和版本核验，环境覆盖仅作用于任务子进程。

**迁移方案**　T06 引入检测和诊断；已有显式选择须保留，失效时提示修复。

**验证证据与验收入口**　T06–T08 和 R1 按 E2E-04/05 核对版本、退出码与环境。

任务状态与实测结果见[交付计划](../../plan/PLAN.md)。
