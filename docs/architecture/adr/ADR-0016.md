# ADR-0016 · 本地历史报告沿用绑定的项目查看权限

状态为 Accepted，2026-11-27，T13。

**背景。** SQLite 保存按绑定隔离的脱敏审计。旧版已检查调用目录和绑定状态，但绑定仍受信时，即使授权已经过期，也能读取和清理记录。

**决定。** `report show` 按 requestId 或 evidenceId 查阅历史，`report clear` 清理本绑定历史。两者都在同一个 SQLite 写事务中验证调用目录、受信绑定、所属项目和当前有效的 `project.inspect`，再访问记录。授权过期或撤销时，CLI 返回 `POLICY_DENIED` 和退出码 3。事务先取得写入锁，撤权和历史操作按提交顺序生效。

**理由与影响。** 项目维护者需要在收回数据库读取权或任务运行权后复核先前的决定。按原操作逐项重验权限会妨碍这种复核。单独设置历史权限可以更细地分配审计职责，但也需要新的能力、签发入口和迁移。首版沿用项目查看权，允许其持有者查看脱敏摘要以及清理本绑定的记录。同一项目下其他绑定的权限不能代用。

**迁移与验证。** 现有记录、编号和授权沿用原格式。已经过期或撤销的项目查看权需要重新授权。本地读写历史不增加 MCP 工具。存储回归验证到期、撤销与重新授权，真实 MySQL 用例分别验证收回数据库读取权后可复查、收回项目查看权后三种历史操作均被拒绝。[T13 验收记录](../../plan/tasks/T13-mcp-cli-contracts.md)
