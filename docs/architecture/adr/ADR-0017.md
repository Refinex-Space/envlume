# ADR-0017 · 桌面随包 CLI 与用户级稳定入口

状态为 Accepted，2026-11-27，T14。

**背景与备选。** 项目配置要在桌面关闭、应用移动或更新后继续启动同一条绝对路径。直接引用开发目录、应用内部路径或依赖 shell 的 PATH 都会把配置与安装位置绑定。Tauri externalBin 可按 triple 分发独立文件，另一种选择是把匹配的 CLI 嵌入原生宿主，由宿主安装。

**决定。** 采用嵌入方式。Tauri hook 用锁定的工作区构建目标 CLI，由 Cargo 生成版本、target triple 和支持的最高 SQLite schema。桌面构建核对版本、目标与 SHA-256，并将 CLI 字节和描述编入原生二进制。安装还校验 Mach-O 或 PE 的架构。Tauri 开发与打包入口启用 `bundled-cli`；普通 Cargo 构建保留原有桌面及仓储测试入口。

**运行与安全。** 桌面启动时尝试安装或升级；维护命令可显式安装、定位和恢复。原生存储适配器从平台应用数据目录取得私有 bin，在数据库迁移锁内校验现存目录库。执行文件复制到同目录临时文件，校验摘要、设置权限并同步，然后发布收据并用一次重命名切换稳定名称。收据允许用实际文件摘要区分重命名前后两种状态。此前的可用二进制保留在私有目录，覆盖失败可重试。恢复前重验备份摘要与当前 schema。显式恢复后，同一桌面包尊重该选择，用户可以显式重装。

**数据与风险。** 切换已有版本前，对已存在且有 schema 的 SQLite 库生成经检查的在线快照，包含已提交 WAL。命名为 `backups/pre-cli-<uuid>.db`。恢复 CLI 只切换程序；旧 CLI 读不了正在使用的 schema 时返回错误。数据迁移及恢复到新目录沿用 T03 的事务机制。Windows 有运行中的映像或共享冲突时返回 BUSY，调用者关闭会话后重试。信任来源为本机原生包和用户专用目录；开发构建的哈希用于完整性核对，发布签名、公证及其更新连续性随 T21 和 V01–V03 验收。

**迁移与交接。** 以前没有安装收据的稳定路径若已含文件，安装器返回校验错误，调用者需先核对该文件。T15 可调用 `envlume_storage::cli_install::locate` 获取校验过的路径与版本，单独传递 MCP 的参数数组。WebView 的 IPC 权限和系统 PATH 沿用既有设置。[T14 验收记录](../../plan/tasks/T14-stable-cli.md)
