# ADR-0005 · SQLite 元数据 + OS 凭据存储，不在数据库保存明文密码

状态为 Accepted，沿用 2026-11-23 [架构 v1.0.0 §20](../ARCHITECTURE.md) 决议。

**背景**　多入口共享配置与审计，需要持久化元数据和可撤销的凭据引用。

**备选方案**　明文配置、应用自管可逆加密密码库。

**决策与理由**　SQLite 保存引用与元数据，原生凭据库保存秘密内容。

**风险**　系统凭据条目可能被删除或损坏，多进程也可能并发写入元数据。

**安全影响**　秘密不经 MCP 或日志返回，凭据失效时要求修复。

**迁移方案**　T03 引入版本化迁移，T10 实现原生 provider 与失效修复。

**验证证据与验收入口**　T03/R0 验同库；T10、V01–V03 检查凭据生命周期，SEC-009 验脱敏。

任务状态与实测结果见[交付计划](../../plan/PLAN.md)。
