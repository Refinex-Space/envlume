# ADR-0003 · 本地 STDIO MCP、无 daemon、独立 per-workspace binding

状态为 Accepted，沿用 2026-11-23 [架构 v1.0.0 §20](../ARCHITECTURE.md) 决议。

**背景**　关闭桌面后 Agent 仍需访问已获授权的项目。

**备选方案**　常驻 daemon、本地管理 HTTP 端口。

**决策与理由**　客户端通过 STDIO 启动绑定单个工作区的进程，减少监听端口与服务生命周期管理。

**风险**　并发进程可能读到变化或撤销的绑定。

**安全影响**　逐次按注册表核验，工具参数不能指定新的调用身份。

**迁移方案**　T04 交付模拟传输，T05 接真实绑定；传输变更须单独评审。

**验证证据与验收入口**　T04 验证协议输出；SEC-001、002、010 和 E2E-11 分阶段取证。

任务状态与实测结果见[交付计划](../../plan/PLAN.md)。
