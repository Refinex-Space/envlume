# ADR-0001 · Tauri 2 + React/TypeScript 桌面

状态为 Accepted，沿用 2026-11-23 [架构 v1.0.0 §20](../ARCHITECTURE.md) 决议。

**背景**　桌面需要在 macOS 与 Windows 提供本地操作入口。

**备选方案**　Electron、分平台开发原生 UI。

**决策与理由**　Tauri 2 使用系统 WebView；React/TS/Vite 负责呈现，特权操作交给 Rust。

**风险**　两个系统的 WebView 行为与部署条件不同。

**安全影响**　本地内容、严格 CSP 及每窗口 capability 限制 WebView。

**迁移方案**　首版新建 Shell；替换 WebView 或桌面框架前重新评估 IPC 和安装路径。

**验证证据与验收入口**　T01-A01/A02 验证启动、编译与权限清单；安装验证见 V01–V03。

任务状态与实测结果见[交付计划](../../plan/PLAN.md)。
