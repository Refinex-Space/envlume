# ADR-0011 · 具名构建的启动入口与 wrapper 确认

状态为 Accepted，2026-11-26 在 T07 实施中确认。

**背景**　Maven 和 Node 包管理器通常附带平台启动脚本。Windows 的批处理解释器有独立的转义、变量展开和命令查找规则。仓库内的 Maven wrapper 还可能下载发行包。

**备选方案**　直接运行安装目录的批处理脚本需要处理命令解释器边界；仅支持已安装的 Maven 会排除使用项目 wrapper 的工作区。

**决策与理由**　已安装 Maven 3 使用所选 Java 启动 Classworlds，包管理器使用所选 Node 和安装包声明的 JS 入口。两种任务的参数固定。用户可为已信任的工作区启用具名任务，在首次构建时批准仓库代码以当前用户权限运行。使用仓库 Maven wrapper 时，须另行展示并确认 HTTPS 分发地址及配置中声明的 wrapper JAR 地址。Windows 经系统目录中的 `cmd.exe` 调用 `.\mvnw.cmd`，工作目录由绑定决定，命令行仅含固定字面量。

**风险**　wrapper、插件和生命周期脚本具有当前系统用户的权限，可以读取用户可访问的文件、启动其他进程或联网。所展示的 URL 来自 wrapper 配置；自定义仓库脚本可以自行发起其他请求。

**安全影响**　授权仅属于当前绑定。启用、首次构建与 wrapper 下载分别确认。影响启动的 wrapper 文件、配置或分发地址变化会使已保存的确认失效。工作进程从空环境构造所需变量，以本地进程组或 Windows Job Object 管理构建。

**迁移方案**　SQLite 迁移 004 向运行授权增加可空的确认时间、摘要和超时字段。升级前的授权须补办首次确认。撤销后新建的授权拥有独立编号。

**验证证据**　T07-A01 至 A03 覆盖未授权启动、真实构建、wrapper 分项确认、工作目录及进程回收。[T07 任务卡](../../plan/tasks/T07-named-task-runner.md)
