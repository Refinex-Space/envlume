# ADR-0019 · Claude Code 个人项目配置与撤销

状态为 Accepted，2026-11-28，T16。

**作用域。** Claude Code 2.1.318 将 local MCP 服务写入当前用户的 `.claude.json`，使用 `projects[projectKey].mcpServers` 区分项目。默认位置在用户主目录，显式设置 `CLAUDE_CONFIG_DIR` 时位于该目录。Envlume 在一次性配置目录调用客户端自己的 `mcp add-json --scope local`，核对客户端选出的项目和已确认的绑定根目录。Git 子目录或 linked worktree 可能归到主仓库；项目根不一致时拒绝安装。客户端从绑定目录以外的原生可执行文件启动。仓库共享模式继续要求 `--shared-project` 和终端确认。[Claude Code MCP 作用域](https://code.claude.com/docs/en/mcp#mcp-installation-scopes)

**配置事务。** 用户确认前展示具体配置位置、项目键、作用域以及拟写入的 command/args。确认后按 ADR-0018 重查目录身份、登记和内容指纹。个人配置采用单次 JSON 插入。备份只记录撤销插入所需的字节偏移和长度；卸载及补偿记录只含通过所有权验证的 Envlume 启动描述。原始字节摘要用于核对恢复，其他项目、账号字段、其他服务的凭据不会进入这些备份。Claude 自身可以修改配置。整文件指纹已变时，在当前文件内只移除仍匹配登记的 Envlume 条目，保留用户编辑；新建的空父对象可能保留。迁移 011 保存客户端项目键，已登记的共享配置继续使用原来的恢复方式。

**验证与信任。** 网关调用 `project_context` 核对绑定；客户端从同一工作目录执行 `claude mcp get envlume`，只有 local 作用域、STDIO、稳定绝对命令、绑定参数和连接状态全部匹配才返回 CONNECTED。首次安装验证失败时回滚，保留客户端禁用选项。已打开的会话可以重新启动并通过 `/mcp` 查看或授权。产品的五个操作仅运行版本和 MCP 管理命令。验收另用独立配置、临时项目和回环 Messages 夹具驱动真实客户端发现工具并通过 STDIO 执行。工具结果与本地审计记录交叉核对。[T16 验收步骤](../../plan/tasks/T16-claude-code-integration.md)
