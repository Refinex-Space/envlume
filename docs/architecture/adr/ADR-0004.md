# ADR-0004 · 项目与部署环境、工具链彼此独立

状态为 Accepted，沿用 2026-11-23 [架构 v1.0.0 §20](../ARCHITECTURE.md) 决议。

**背景**　同一 JDK 可以对应多个部署环境，同一项目也可以有多个 worktree。

**备选方案**　按环境复制项目和工具链，或按 Git remote 共用绑定。

**决策与理由**　分别建模 Project、WorkspaceBinding、ToolchainProfile 和 EnvironmentTarget，资源隶属目标。

**风险**　重名资源、工作区移动或默认环境可能导致误用。

**安全影响**　授权显式关联绑定、目标和资源；生产目标不能自动成为默认值。

**迁移方案**　T02 固化实体，T03 建立初始存储；后续字段迁移按 §10.5 处理。

**验证证据与验收入口**　T02 契约、E2E-05、006 和 SEC-003 在对应阶段取证。

任务状态与实测结果见[交付计划](../../plan/PLAN.md)。
