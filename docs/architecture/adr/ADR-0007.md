# ADR-0007 · 项目级客户端集成使用配置适配器，支持回滚

状态为 Accepted，沿用 2026-11-23 [架构 v1.0.0 §20](../ARCHITECTURE.md) 决议。

**背景**　客户端项目配置格式不同，用户可能已有其他工具条目。

**备选方案**　写入全局配置，或覆盖整个配置文件。

**决策与理由**　通过客户端适配器预览、备份、合并、验证和回滚，控制修改范围。

**风险**　客户端格式演进或并发编辑可能覆盖第三方修改。

**安全影响**　按项目记录配置指纹、绑定及所有权，拒绝不安全写入。

**迁移方案**　T15 定义共同生命周期，T16–T18 按实际客户端版本迁入。

**验证证据与验收入口**　SEC-011 与 E2E-08–10 由 T15–T18 实机验证。

任务状态与实测结果见[交付计划](../../plan/PLAN.md)。
