# ADR-0010 · v0.1 不承诺 OS 级隔离，不暴露任意 Shell/SQL 写接口

状态为 Accepted，沿用 2026-11-23 [架构 v1.0.0 §20](../ARCHITECTURE.md) 决议。

**背景**　宿主 Agent 可拥有独立终端，构建脚本本身也会执行仓库代码。

**备选方案**　公开通用 Shell/SQL 写接口，或宣称默认提供系统沙箱。

**决策与理由**　网关只提供已批准的具名任务与受限资源操作，明确宿主权限边界。

**风险**　恶意构建脚本仍拥有执行用户所赋的本机权限。

**安全影响**　先信任工作区并首次确认，收窄子进程环境，不向模型提供任意执行入口。

**迁移方案**　T07 承担具名执行；更强系统隔离按 T31 独立决策。

**验证证据与验收入口**　SEC-004、006、012 分别核对生产写入、SQL 与工作区执行边界。

任务状态与实测结果见[交付计划](../../plan/PLAN.md)。
