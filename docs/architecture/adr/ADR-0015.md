# ADR-0015 · MySQL 行数据授权与查询边界

状态为 Accepted，2026-11-27，T12。

**授权。** 本地操作者为每个资源单独确认可读列、遮蔽列和限额。两类列必须属于已批准的元数据清单。SQLite 迁移 009 给已有资源保留空查询策略。首次配置或更改策略时撤销该资源所有绑定的 `database.read`，端点、路由或元数据范围变化时清除查询策略。调用时检查当前绑定、DEV/TEST 的风险等级、资源、授权及策略。

**查询。** policy 用锁定的 `sqlparser 0.64.0` 解析 MySQL 方言，识别单表或递归派生表上的列投影、别名、通配符、比较、布尔条件、排序、整数 LIMIT 和独立的 `COUNT(*) AS alias`。通配符按本地清单展开。SQL 在连接器调用前重新生成，标识符限制为 ASCII 名称并引用，条件字面值作为驱动参数。遮蔽列仅供直接投影，投影在数据库侧生成固定文本，派生别名继承遮蔽属性。当前语法范围、全局授权或空闲池均不能扩大调用方的本地授权。

**数据库身份。** 每次查询读取当前账号的有效角色和直接授权。首版支持无活动角色、仅有 USAGE 和 SELECT 且没有转授能力的账号。查询使用显式只读事务。连接器沿用 T11 的主机名验证、固定拨号地址和授权池键，查询完成或截止后处置本次连接。

**输出与证据。** 本地配置可收紧 5 秒、200 行和 256 KiB 三项上限。MySQL 执行时间提示、锁等待上限与驱动截止时间共同限制等待。多取一行判定行数截断，过大的行在服务端标记。驱动逐行计入 JSON 及 MCP 文本副本的转义开销，为报告、协议和请求编号预留空间。审计按 evidenceId 保存行列数、遮蔽列数、截断标志、耗时、授权范围和结果状态。原始查询和行值仅在本次调用内使用。
