# ADR-0006 · AI 能力默认拒绝；v0.1 基础设施只读

状态为 Accepted，沿用 2026-11-23 [架构 v1.0.0 §20](../ARCHITECTURE.md) 决议。

**背景**　模型工具参数、资源响应与仓库内容均可能不可信。

**备选方案**　对已连接资源默认放行，在名称或提示词中约束操作。

**决策与理由**　在 Rust 内逐请求核验显式授权；首版限只读基础设施操作。

**风险**　只读查询仍可能读取敏感字段或消耗过多资源。

**安全影响**　只读身份、语句与表列白名单、资源预算及脱敏共同约束结果。

**迁移方案**　按 T09–T13 接入目标判定与查询；扩展写操作需先有新 ADR。

**验证证据与验收入口**　R2 复验 SEC-003–007，T22 对候选版重跑。

任务状态与实测结果见[交付计划](../../plan/PLAN.md)。
