# ADR-0009 · v0.1 仅 MySQL，不提前并行开发 Redis/ES/SSH

状态为 Accepted，沿用 2026-11-23 [架构 v1.0.0 §20](../ARCHITECTURE.md) 决议。

**背景**　首发资源能力需要可在真实环境证明授权隔离。

**备选方案**　多个连接器同时进入 v0.1。

**决策与理由**　集中交付 MySQL 元数据、受限 SELECT 与证据，后续按阶段扩展。

**风险**　其他资源类型需要等待，过早抽象也可能固化 MySQL 特性。

**安全影响**　每种新连接器独立评估权限和输入边界。

**迁移方案**　MySQL 在 T11–T13 接入；Redis、ES、SSH 按 T23–T25 单独交付。

**验证证据与验收入口**　R2 验收双目标 MySQL；R4 对入选连接器重新验收。

任务状态与实测结果见[交付计划](../../plan/PLAN.md)。
