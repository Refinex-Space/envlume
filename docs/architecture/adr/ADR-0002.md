# ADR-0002 · Rust 单核心，CLI/MCP/UI 共享应用服务

状态为 Accepted，沿用 2026-11-23 [架构 v1.0.0 §20](../ARCHITECTURE.md) 决议。

**背景**　同一资源可从桌面、CLI 和 MCP 访问，授权结果需要一致。

**备选方案**　各入口独立实现用例，或以桌面进程作为唯一服务端。

**决策与理由**　三个适配器调用 Rust application，domain 只承载领域模型。

**风险**　界面或连接器直接访问存储会造成策略分叉。

**安全影响**　策略检查发生在共享用例内，各入口的参数都需校验。

**迁移方案**　T01 建立依赖方向，T02 定义契约；迁移入口时以同一组用例复验。

**验证证据与验收入口**　T01-A02 检查依赖图；T13 与 R2 对照入口行为。

任务状态与实测结果见[交付计划](../../plan/PLAN.md)。
