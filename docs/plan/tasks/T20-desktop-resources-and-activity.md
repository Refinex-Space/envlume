## 交付目标

用户从桌面为当前项目配置 DEV MySQL、按能力授权并接入 Agent，可追查一次查询或构建。

## 实施与产出

1. 完成 Environments、Connections、Integrations、Activity、Settings。明确显示项目、目标文字、风险等级及授权范围。连接表单按目标/TLS/凭据/测试/授权分步，支持引用损坏后的重新录入。
2. 接通三客户端的预览、安装、验证、还原与卸载，统一首次启动路径，允许跳过非必需步骤并继续。区分版本不兼容、缺工具、凭据缺失、VPN/DNS 不通、认证和策略拒绝。
3. Activity 展示 Success/Failed/Denied/Skipped、requestId/evidenceId、时间和脱敏摘要，可筛选、复制、清理。Settings 提供外观、日志保留、安全状态、更新入口及脱敏诊断导出。更新后端由 T21 接通。
4. 凭据表单一次提交后清空，前端状态持久化、日志与错误上报均不收录。所有资源、策略与凭据操作由 Rust 后端校验。

## 验收

- **T20-A01**　用本地测试项目在 ego-browser 走完引导、DEV/TEST 同名资源切换、连接失败修复、授权撤销、客户端接入与查看报告，再在原生桌面复核实际 Keychain/Credential Manager 和客户端配置操作。
- **T20-A02**　仅用键盘完成新增连接、取消和错误修复。屏幕中始终能读到目标名和风险。非可信日志/行内容按文本展示，假秘密不进入 UI 回显、导出或复制结果。
- **T20-A03**　证据行可定位 T08/T12 的真实结果，清理后查询/导出符合保留策略。首次引导重开可继续，已安装集成不会重复或误报成功。
