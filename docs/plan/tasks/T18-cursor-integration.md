## 交付目标

让 Cursor 从项目目录发现已登记的网关，验证实际调用和项目切换后的隔离。

## 实施与产出

1. 在测试项目按当前客户端格式适配 .cursor/mcp.json，复用 T15 五步流程。提醒绝对路径和 binding 的本地属性，展示忽略配置或可移植模板的选项及实际文件差异。
2. 记录真实客户端的重载/启用步骤和发现失败诊断。测试已有其他服务、两个项目同名目录以及安装配置被用户编辑的情形。

## 验收

- **T18-A01**　E2E-10 在真实 Cursor 完成安装、工具发现、project_context、卸载，记录客户端与协议版本。切换项目只能得到所选绑定的上下文。
- **T18-A02**　核对预览、失败回滚、重复安装及卸载后的 JSON，无关条目保留。用户未确认时不会修改仓库其他文件。

## 交接

移交 Cursor 的真实 POC 与回滚证据，并汇总三客户端按版本实测的作用域、重载和差异。
