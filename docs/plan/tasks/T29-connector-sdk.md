## 交付目标

用受控示例连接器证明扩展作者能复用网关授权、限流与审计约束。

## 实施与产出

1. 先用已确认的扩展需求与 v0.2 连接器比较，确定 SDK 的调用边界、注册方式、版本兼容及责任归属。对外接口变更走 ADR。
2. 定义类型化能力声明、健康/关闭、输入输出验证、超时与流控契约。提供示例与一致性测试，按已批准的加载模式实施。

## 验收

- **T29-A01**　示例走真实 application 和 policy，仅访问获准目标。用测试替身证明拒绝先于取密钥和连接。旧接口版本获得可诊断的兼容结果。
- **T29-A02**　扩展发布前通过权限、越权、误连、取消/回收、脱敏和版本测试。未选入当前版本时记录需求和后续触发条件。

## 交接

移交 SDK 接口、示例、契约套件及适用版本，或记录延期决定。
