## 交付目标

按此次版本实际开放的连接器和任务模板裁决 v0.2 的交付范围。

## 实施与产出

1. 汇总 Redis、ES、SSH、Gradle 的真实目标/版本、权限矩阵、超时、TLS/主机密钥、恶意输入、脱敏与误连用例。逐项核对进入 MCP 目录前的测试记录。
2. 复跑 v0.1 的八项工具、绑定及只读默认策略、客户端兼容、元数据升级与三平台安装抽测。涉及平台或安装行为的改动按 R3 原生矩阵重验。

## 验收

- **R4-A01**　US-10、US-11 和新增任务模板有实际请求、结果和证据。客户端仅发现获准扩展，未启用的 US-12 不出现在支持清单中。
- **R4-A02**　若 T27 已启用，审查已采纳 ADR 与完整的一次性批准、拒绝和并发证据。若延期，在版本说明列明。核对版本、制品及升级证据后记录发布决定。

## 交接

记录 v0.2 支持矩阵、已选范围与发布/阻塞结论，为下一阶段保留可复测的兼容基线。
