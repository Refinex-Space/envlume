## 交付目标

对同一候选版本作发布裁决，通过后交付可下载、可校验、可安装的 v0.1。

## 实施与产出

1. 汇总 T22、V01–V03 及三个真实客户端矩阵。逐项核对 §19.1、§19.2、§19.3 和 §1.3 十二条不变量，列出平台、修订、包哈希、证据位置与结论。
2. 核查依赖清单、签名/公证、SHA-256、恢复步骤、版本说明与安全限制。清点全部 P0、失败、缺测和适用的性能目标差异。修复后重建候选，补跑受影响矩阵。
3. 写出发布或阻塞决定。在已有发布授权下执行 GitHub Release，核对版本/tag 对应提交、上传的 DMG/NSIS/独立 CLI 与校验文件，并从发行页重新取得制品核对哈希。待授权发布时保留“待发布”检查点。

## 验收

- **R3-A01**　发布前，E2E-01 至 E2E-12、SEC-001 至 SEC-012、原生安装/卸载/升级、客户端闭环和恢复均有通过证据。任何 P0 失败或强制项缺证据均不能放行。
- **R3-A02**　发行页公开范围、平台及版本说明准确。下载件与验收件 SHA-256 一致，可据说明安装及查阅安全限制。若只得到候选包，状态仍停留在候选验收。
