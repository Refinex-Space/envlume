## 交付目标

对照已确认的 v1.0 范围验收共享模板，列明企业能力实际交付版本和适用条件。

## 实施与产出

1. 汇总 T28–T31 的范围决定、数据兼容性、授权和支持平台。以从 v0.1/v0.2 已有数据升级、模板迁移到新工作区、逐项重新绑定为主场景。
2. 复核选入的 SDK、凭据 Broker、网络代理、隔离执行各自的安全与恢复测试。沿用 R3 的平台、客户端、供应链及发布证据规则。

## 验收

- **R5-A01**　在独立测试工作区回放 US-13。原项目仍可运行，导出物无私有字段，模板不自行授予权限。包、CLI、MCP、schema 及模板 API 的兼容边界有实测记录。
- **R5-A02**　每个对外声明的能力均有版本、平台和证据。US-14 仍在 v1.0+ 的条目逐项列明，有阻塞或未完成的已承诺项时停止相应发布。

## 交接

登记最终版本、支持矩阵、制品和升级证据，将后续候选需求保留在其实际目标版本。
