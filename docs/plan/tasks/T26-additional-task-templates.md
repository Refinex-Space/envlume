## 交付目标

在 v0.1 已验证的 Task Runner 之上补齐 Gradle 执行与有需求的固定任务模板。

## 实施与产出

1. 复用 ToolchainProfile、TaskDefinition 和现有进程控制。优先处理 Gradle/JDK 与 wrapper 的绑定。根据实际项目选定更多模板，逐项列出固定参数、工作目录、超时和需要的授权。
2. 模板导入后由本地用户选择启用。wrapper 执行和下载分别满足工作区信任、来源与网络批准，模板不会扩大已有 grants。

## 验收

- **T26-A01**　真实 Gradle 项目使用指定 JDK 运行测试并返回证据。在两个原生系统验证绝对路径、取消与超时处理，父进程环境不变。
- **T26-A02**　另测不可信仓库、未批准下载、缺依赖和篡改参数，拒绝时不创建进程。既有 Maven 和 Node 任务回归通过。

## 交接

移交受支持模板清单、工具版本、双平台执行及拒绝报告。
