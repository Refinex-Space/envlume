## 交付目标

在干净 macOS Apple Silicon 用户环境验证将要分发的 DMG、独立 CLI 和本地数据恢复。

## 实施与产出

1. 核对候选包哈希、arm64 架构、Developer ID 和 Apple 公证。用系统正常安装路径测试首次启动、卸载、重装与兼容基线升级，记录系统放行和使用的账号类型。
2. 从安装版导入测试项目、保存测试凭据、运行任务。退出桌面后让真实客户端用已安装的 CLI 调用 MCP。断网和无终端 PATH 时复查本机能力。

## 验收

- **V01-A01**　E2E-01、E2E-11、E2E-12 有安装包哈希、OS、CLI 版本及真实报告。卸载/重装的数据行为有提示，测试数据与真实用户目录隔离。
- **V01-A02**　升级或触发迁移失败后，备份、资源映射、Keychain 引用和集成路径可恢复。复核首次可交互和工具诊断的本机测量。
