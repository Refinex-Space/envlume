## 交付目标

新用户可以在桌面导入项目、核对信任与工具链、启用具名任务并查看实际构建结果。

## 实施与产出

1. 在 Tauri Shell 建立稳定导航、项目切换和明暗主题，使用语义 token、Tailwind、shadcn/ui、Radix 和 Lucide。完成 Overview、Projects、Toolchains 和引导中的本机步骤。
2. 通过类型化 command 封装现有用例。展示 worktree/STALE、技术栈建议、版本来源与冲突、修复入口。允许选择已有工具路径、确认首次执行、取消任务并查看版本和退出结果。
3. 保持最小 Tauri capabilities 与严格 CSP。表单支持键盘、可见焦点、字段错误及辅助技术标签。外部链接交给受控系统浏览器，日志或数据库文本按纯文本呈现。

## 验收

- **T19-A01**　用本地测试项目在 ego-browser 走通导入、拒绝/同意信任、选择 JDK、运行/取消与失败诊断。再在真实 Tauri 窗口验证文件选择、原生 IPC 和进程执行。
- **T19-A02**　切换项目后工具链/任务随绑定切换，缺失工具提供对应修复，旧任务结果不会显示为新项目的结果。核对键盘流程、两种主题及错误焦点。
- **T19-A03**　从 WebView 只能调用明确声明的命令。检查打包配置无开放式 shell、数据库、凭据或任意出网能力。
